# Изменения по файлам

База: `swarm100`, commit `85a0a2e1ff9993929b95d52646385a3b36fc2289`.

Диагностики: `experiment-attention-katya`, commit `280800367d868d888424a1cab573f98a2d1e87d6`.

Архитектура сети, веса и законы динамики не изменены. Случайная среда сохранена.
