# Парный координатор и канал приоритета

В каждом режиме сравнивали восемь коридоров и восемь парных тупиков, по одному набору стартов на геометрию (сид `50000`). Датчики штатные, лимит 15 с симуляции. Безаварийный долёт засчитывали при удержании в радиусе 0,3 м от цели в течение 0,5 с и отсутствии контактов за весь эпизод. [Лётная политика на 1 млрд](../swarm100-1b/checkpoints/checkpoint_000781254_1000005120.pth) и [конфиг](../swarm100-1b/config.json) общие для всех сравнений.

## Горизонт прогноза парного координатора

64 эпизода на 100 дронах, чекпоинт координатора на 100 млн, лимит 64 пары. Для каждого горизонта использовали те же восемь коридоров и восемь тупиков. В таблице результаты коридоров.

| Горизонт | Долетели без контакта | Дроны с контактом до 1,5 с | Дроны с контактом за эпизод |
|---:|---:|---:|---:|
| 0,25 с | 190/800 (23,75%) | 313 | 604 |
| 0,50 с | 187/800 (23,38%) | 303 | 604 |
| **0,65 с** | **219/800 (27,38%)** | 280 | 563 |
| 0,70 с | 212/800 (26,50%) | 266 | 573 |

При 0,65 с получили на 29 безаварийных долётов больше, чем при 0,25 с. На широкую U-камеру пришлось 20 из 29. Парный тест с перестановкой знаков по восьми коридорам дал `p = 0,15625`. Повторный контроль на 0,25 с воспроизвёл результаты теста лимита пар. [Сводка](pair/horizon/comparison.csv) · [48 эпизодов](pair/horizon/episodes.csv) · [Манифест](pair/horizon/manifest.json)

На ПК продолжили проверку с шагом 0,05 с от 0,65 с до первого снижения числа долётов. На 0,70 с получили на 7 безаварийных долётов меньше (−0,88 п.п.) и остановились. Для сравнения 0,65 и 0,70 с тот же парный тест дал `p = 0,578125`. В тупиках на каждом из четырёх горизонтов было 0 долётов из 800. [Сводка 0,70 с](pair/horizon/h070/comparison.csv) · [16 эпизодов](pair/horizon/h070/episodes.csv) · [Манифест](pair/horizon/h070/manifest.json) · [Критерий остановки и результат](pair/horizon/sweep.json)

## Усиленный канал и вклад сообщений

С одним чекпоинтом на 100 млн сравнили решение об уступании напрямую и через проверку прогнозируемого конфликта. При прямом управлении на 100 дронах усиленный канал дал **135/800** безаварийных долётов с выключенными сообщениями и **104/800** с включёнными. При проверке конфликта получили **258/800**, а при одном только выученном порядке в фильтре — **242/800**. Статическое торможение дало **186/800**.

## Запуск

Команды из корня `swarm100`. `QUADSWARM_SIM` указывает на checkout [симулятора `7f4596e`](https://github.com/Vikvins/quad-swarm-rl/tree/7f4596ee06d9d55dcb98ed985ab4a4fcc025fc20).

```bash
base=experiments/swarm100-1b
run=experiments/priority-coordinator-1b
report=experiments/coordination-followup
flight=$base/checkpoints/checkpoint_000781254_1000005120.pth
pair=experiments/pair-priority-100m/frozen/checkpoint_000100000000.pt
reference=experiments/pair-priority-100m/results/frozen-flight/episodes.csv
export PYTHONPATH="$PWD/experiments/priority-diagnostics:$QUADSWARM_SIM"
export PYGLET_HEADLESS=true MPLBACKEND=Agg
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMBA_NUM_THREADS=1

python "$run/validate_pair_capacity.py" --config "$base/config.json" --flight "$flight" \
  --coordinator "$pair" --reference "$reference" --output /tmp/quads-pair-capacity
python "$run/validate_pair_horizon.py" --config "$base/config.json" --flight "$flight" \
  --coordinator "$pair" --reference /tmp/quads-pair-capacity --output /tmp/quads-pair-horizon
python "$run/validate_pair_200m.py" --config "$base/config.json" --flight "$flight" \
  --coordinator "$report/pair/checkpoints/checkpoint_000200000000.pt" --reference "$reference" \
  --output /tmp/quads-pair-200m
python "$run/validate_goal_channel.py" --config "$base/config.json" --flight "$flight" \
  --peer "$report/channel/checkpoints/checkpoint_000200000000.pt" \
  --reference "$report/channel/messages/episodes.csv" --output /tmp/quads-channel-200m
```

Для масштаба 200 и 300 используй [раннер](../priority-coordinator-1b/evaluate_pair_scaling.py) и [патч размещения](../scaling-725m/spawn-capacity.patch) к файлу `gym_art/quadrotor_multi/obstacles/suite_layouts.py`. Для проверки сообщений используй [раннер подмены](../priority-coordinator-1b/evaluate_messages.py) и результаты [раннера с фильтром](../priority-coordinator-1b/evaluate_gated_priority.py) как референс. [Код дообучения канала](../priority-coordinator-1b/train_goal_channel.py)
