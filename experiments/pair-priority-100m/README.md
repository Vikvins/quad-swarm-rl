# Парный координатор на 100 дронах

Из пар дронов выбираются до 64 наиболее опасных на сцену. Горизонт прогноза 0,25 с. Сеть выдаёт одно число приоритета на дрон. [Код выбора пар и координатора](../priority-coordinator-1b/pair_priority.py)

## Веса

| Прогон | Шаги агента | Чекпоинт | Обучение |
|---|---:|---|---|
| Замороженная полётная политика | 100 000 000 | [Веса координатора](frozen/checkpoint_000100000000.pt) | [Сводка](frozen/training-summary.json) |
| Совместное обучение с нуля | 100 000 000 | [Веса обеих сетей](joint/checkpoint_000100000000.pt) | [Сводка](joint/training-summary.json) · [Метрики по обновлениям](joint/training-metrics.jsonl) |

Для первого прогона использовали [лётный чекпоинт на 1 млрд](../swarm100-1b/checkpoints/checkpoint_000781254_1000005120.pth). Во втором 0 долётов за 640 завершённых сцен обучения. Отдельная валидация совместного прогона пока не проводилась.

## Валидация замороженного прогона

На каждый размер роя — 8 коридоров и 8 тупиков, один набор стартов на геометрию (сид 50000), 15 с симуляции, штатные датчики. Долёт засчитывали при удержании в радиусе 0,3 м от цели в течение 0,5 с и отсутствии контактов за эпизод.

| Полётная база на 1 млрд, коридоры | 8 дронов | 100 дронов |
|---|---:|---:|
| Без приоритета | 37/64 | 123/800 |
| Парный механизм с порядком по номеру | 44/64 | 146/800 |
| Парный механизм с выученным приоритетом | **47/64** | **191/800** |

При переносе этого же координатора на базу, обученную на 8 дронах до 100 млн, безаварийные долёты изменились с 20 до 19 из 64 на 8 дронах и с 86 до 87 из 800 на 100. На базе, обученной на 100 дронах до 100 млн, во всех этих коридорах было 0 долётов. В проверенных тупиках все варианты дали 0 безаварийных долётов.

### Запуск

Из корня ветки `swarm100` с [симулятором `7f4596e`](https://github.com/Vikvins/quad-swarm-rl/tree/7f4596ee06d9d55dcb98ed985ab4a4fcc025fc20) по пути `QUADSWARM_SIM`.

```bash
base=experiments/swarm100-1b
PYTHONPATH="$QUADSWARM_SIM" OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMBA_NUM_THREADS=1 \
  python experiments/priority-coordinator-1b/train_priority.py pair --config "$base/config.json" \
    --train-flight --agents 100 --arenas 32 --pairs 64 --horizon 0.25 --refresh 0.1 \
    --train-steps 100000000 --checkpoint-steps 1000000 --output /tmp/quads-pair-joint
```

Для замороженного обучения замени `--train-flight` на `--flight-checkpoint` с лётными весами на 1 млрд и укажи другой каталог вывода. Параметры проверки выводит `python experiments/priority-coordinator-1b/evaluate_pair_checkpoint.py --help`.
