# Канал приоритета только при обучении — 100 дронов

Политика учится выдавать число намерения соседям и выбирать, уступать ли им. Канал периодически отключается на весь эпизод. При тесте планируется лететь с полностью отключённым каналом. Лётная политика заморожена.

Цель — 1 млрд шагов агентов. Использованы шесть параллельных сцен на 100 дронах, по три экземпляра узкого коридора и парного тупика. Запуск выполнен на облачной RTX 3070.
