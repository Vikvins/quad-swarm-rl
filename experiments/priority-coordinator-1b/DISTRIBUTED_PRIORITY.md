# Децентрализованный динамический приоритет

Режим `distributed_ranker` использует замороженную полётную политику [swarm100-1b](../swarm100-1b/) и веса ранее обученного [координатора](priority.pt). Оценщик запускает оба компонента без обновления весов. Подготовка координатора описана в [основном отчёте](README.md).

1. На каждом шаге дрон вычисляет индивидуальную оценку по своей позиции, скорости и вектору до цели. Исходная линейная голова координатора добавляет к индивидуальной оценке общий для роя скаляр. Его можно убрать, сохранив порядок оценок с точностью до округления.
2. Дрон сравнивает оценку с оценками наблюдаемых соседей и прогнозирует сближение. Если сосед с исходно меньшим приоритетом может перекрыть точку зависания уступающего дрона, уступающий передаёт ему свою текущую срочность.
3. Каждый получатель берёт максимум собственной срочности и полученных значений. Срочность передаётся дальше синхронными раундами до стабилизации. После сравнения итоговых приоритетов уступающий дрон временно получает цель зависания. При равенстве действует исходный порядок.
   
В [оценщике](evaluate_priority.py) синхронные сообщения реализованы операциями над массивами симулятора. Задержки, потери сообщений и физический канал связи в этих опытах отсутствовали.

## Результаты на 100 дронах

Восемь геометрий с открытым выходом, сиды `50003`, `50004` и `50005`, по 15 секунд симуляции. Для каждого режима есть 24 эпизода и 2400 наблюдений по дронам. Внутри пары «сцена и сид» совпадают хеши геометрии, стартов и целей.

| Режим | Достигли цели без контактов | Достигли цели | Контакт с другим дроном |
| --- | ---: | ---: | ---: |
| Полётная политика без приоритетов | 16,96% | 68,75% | 82,58% |
| Статическое торможение | 23,54% | 60,92% | 74,71% |
| Фиксированный ранг с локальным уступанием | 22,38% | 65,67% | 76,63% |
| Обученный координатор | 24,42% | 65,79% | 74,00% |
| Децентрализованный динамический приоритет | 24,42% | 65,79% | 74,00% |

Относительно полётной политики без приоритетов чистый долёт вырос на **7,46 п. п.**, долёт с учётом контактов снизился на **2,96 п. п.**, контакты с другими дронами снизились на **8,58 п. п.** Чистый долёт увеличился на всех трёх сидах (+5,88, +7,38 и +9,13 п. п.). Парный 95%-й бутстреп-интервал для изменения чистого долёта по восьми геометриям составил от +3,88 до +10,63 п. п. Разница со статическим торможением составила +0,88 п. п. с интервалом от −0,79 до +2,71 п. п. Все три табличные метрики динамики и исходного координатора совпали в каждой паре эпизодов. Эти числа относятся к открытым сценам.

Исходные CSV: [50003](results/distributed-ranker/episodes-n100-50003.csv), [50004](results/distributed-ranker/episodes-n100-50004.csv), [50005](results/distributed-ranker/episodes-n100-50005.csv). В каждом CSV строка соответствует одному эпизоду. Столбец `success_rate` содержит долю дронов, достигших цели без контактов. `reached_goal_rate` включает долёт с контактами, а `neighbor_collision_rate` учитывает дронов с хотя бы одним междроновым контактом. [Манифест исходного прогона 50005](results/distributed-ranker/manifest-n100-50005.json) фиксирует хеши исходного оценщика, статического торможения и чекпойнтов.

## Повторный запуск

В окружении QuadSwarm установи `QUADSWARM_SIM` на абсолютный путь к checkout [симулятора 7f4596e](https://github.com/Vikvins/quad-swarm-rl/tree/7f4596ee06d9d55dcb98ed985ab4a4fcc025fc20). Запусти из корня ветки с экспериментом. Для полётного чекпойнта нужен Git LFS.

```bash
run=experiments/priority-coordinator-1b
base=experiments/swarm100-1b
for seed in 50003 50004 50005; do
  PYTHONPATH="$QUADSWARM_SIM" PYGLET_HEADLESS=true MPLBACKEND=Agg \
    OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMBA_NUM_THREADS=1 \
    python "$run/evaluate_priority.py" --config "$base/config.json" \
      --flight "$base/checkpoints/checkpoint_000781254_1000005120.pth" \
      --coordinator "$run/priority.pt" --agents 100 --seed "$seed" --open-only \
      --modes baseline static_brake coordinator fixed_rank_local distributed_ranker \
      --workers 2 --output "results/distributed-ranker/n100-$seed" || break
done
```

Опубликованные CSV получены с архивной версией экспериментального скрипта. Команда запускает тот же протокол в обновлённом оценщике и записывает отдельный манифест с актуальными хешами.
