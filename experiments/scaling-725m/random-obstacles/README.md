# 200 и 300 дронов со случайными препятствиями

[Чекпоинт 725 738 240](../../swarm100-1b/checkpoints/checkpoint_000566983_725738240.pth), обученный на 100 дронах. На ПК проверили те же 16 сцен со случайными препятствиями (сиды 50000–50015) на 200 и 300 дронах. Каждую сцену запустили трижды с разным шумом симуляции. В каждом повторе сравнили штатный датчик, заморозку на 0,5 с и заморозку на 2 с. Всего 288 эпизодов.

Стены комнаты, карта препятствий, старты и цели одинаковы между повторами одной сцены. Для размещения 200 и 300 дронов в свободных клетках доступны три высотные позиции в диапазоне 1–3 м. При сбое у четверти дронов фиксируются последние девять показаний датчика препятствий. Собственное состояние и данные о соседях продолжают обновляться. Группа сбоя и момент его начала фиксированы для каждой сцены. В каждом повторе три режима используют один сид шума, совпадение наблюдений при старте, действий и состояний до сбоя проверили по хешам.

### Результаты трёх повторов

В таблице приведена средняя доля дронов, долетевших без столкновений. Сначала усреднили три повтора каждой сцены. По 16 средним посчитали среднюю долю и выборочную дисперсию `s²` в п.п.². В штатном режиме среднюю долю для группы сбоя считали по тем же дронам, которым замораживали датчик в двух остальных режимах.

| Дронов | Датчик | Весь рой | s², п.п.² | Группа сбоя | s², п.п.² | Остальные дроны | s², п.п.² |
|---:|---|---:|---:|---:|---:|---:|---:|
| 200 | Штатный | 84,50% | 7,51 | 85,83% | 25,69 | 84,06% | 8,35 |
| 200 | Заморозка 0,5 с | 84,46% | 8,18 | 84,42% | 33,12 | 84,47% | 10,25 |
| 200 | Заморозка 2 с | 83,63% | 8,25 | 81,42% | 45,98 | 84,36% | 9,59 |
| 300 | Штатный | 79,31% | 11,52 | 78,97% | 11,74 | 79,42% | 12,86 |
| 300 | Заморозка 0,5 с | 79,04% | 11,23 | 77,94% | 12,45 | 79,41% | 13,02 |
| 300 | Заморозка 2 с | 78,57% | 11,60 | 75,75% | 15,06 | 79,51% | 13,10 |

| Дронов | Заморозка | Изменение по рою, п.п. | Изменение в группе сбоя, п.п. | Изменение у остальных, п.п. |
|---:|---|---:|---:|---:|
| 200 | 0,5 с | −0,04 | −1,42 | +0,42 |
| 200 | 2 с | **−0,88** | **−4,42** | +0,31 |
| 300 | 0,5 с | −0,26 | −1,03 | −0,01 |
| 300 | 2 с | **−0,74** | **−3,22** | +0,09 |

Жирным выделены результаты с `p < 0,05` после поправки Холма на 12 сравнений. Для каждого сравнения посчитали парную разницу со штатным режимом, усреднили три разницы внутри каждой сцены и применили двусторонний тест с перестановкой знаков 16 парных разностей. Весь рой долетел без столкновений в 0 из 48 эпизодов для каждой пары «размер роя — режим».

### Запуск трёх повторов

Из корня ветки `swarm100`. `QUADSWARM_SIM` указывает на [симулятор `7f4596e`](https://github.com/Vikvins/quad-swarm-rl/tree/7f4596ee06d9d55dcb98ed985ab4a4fcc025fc20).

```bash
base=experiments/swarm100-1b
test_dir=experiments/scaling-725m/random-obstacles
out=/tmp/quads-random-repeats
PYTHONPATH="$PWD/experiments/swarm8-1b:$QUADSWARM_SIM" \
  OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMBA_NUM_THREADS=1 \
  PYGLET_HEADLESS=true MPLBACKEND=Agg python "$test_dir/evaluate_repeats.py" \
  --config "$base/config.json" \
  --checkpoint "$base/checkpoints/checkpoint_000566983_725738240.pth" \
  --reference "$test_dir/results" --output "$out" --workers 16
python "$test_dir/summarize_variance.py" "$out"
```

В версии `evaluate.py` на ПК размер пакета сцен в старом CLI был равен 5, в ветке он равен 1. Раннер повторов вызывает класс `Evaluation` напрямую.

### Запуск первого прогона

Из корня ветки `swarm100`. `QUADSWARM_SIM` указывает на [симулятор `7f4596e`](https://github.com/Vikvins/quad-swarm-rl/tree/7f4596ee06d9d55dcb98ed985ab4a4fcc025fc20).

```bash
base=experiments/swarm100-1b
printf '%s\n' "$base/checkpoints/checkpoint_000566983_725738240.pth" > /tmp/quads-random-checkpoint.txt
for n in 200 300; do
  PYTHONPATH="$PWD/experiments/swarm8-1b:$QUADSWARM_SIM" OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMBA_NUM_THREADS=1 \
    python experiments/scaling-725m/random-obstacles/evaluate_capacity.py --config "$base/config.json" \
      --manifest /tmp/quads-random-checkpoint.txt --agents "$n" --episodes 16 --workers 12 \
      --output "/tmp/quads-random-n$n.csv"
done
```
