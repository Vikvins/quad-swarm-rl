# QuadSwarm — обучение на 8 дронах

Обучение до 1 млрд шагов агентов. Основной прогон продолжен с исходного чекпоинта на 100 млн, с батчем 1 024 и 16 воркерами. [Конфиг обучения](config.json) · [Конфиг теста](eval-config.json) · [Общая сводка](results/summary.csv)

На каждом размере роя использовали 16 сцен со случайными препятствиями (сид 50000–50015). Для каждого чекпоинта прогоняли те же сцены без отказа и с заморозкой показаний датчика препятствий на 0,5 или 2 с у четверти дронов. Состав этой четверти и момент начала сбоя зафиксированы для каждой сцены.

В ячейках — **доля дронов, долетевших без столкновения с препятствием или другим дроном / доля сцен, где так долетел весь рой**.

### Запуск теста

Из корня репозитория, в окружении QuadSwarm. Для теста на 100 дронах замени `--agents 8` на `--agents 100`.

```bash
run=experiments/swarm8-1b
printf '%s\n' "$run/checkpoints/checkpoint_000976563_1000000512.pth" > /tmp/quad-swarm8-checkpoints.txt
python "$run/evaluate.py" --config "$run/eval-config.json" \
  --manifest /tmp/quad-swarm8-checkpoints.txt --agents 8 --episodes 16 --workers 8 \
  --output /tmp/quad-swarm8-episodes.csv
```
